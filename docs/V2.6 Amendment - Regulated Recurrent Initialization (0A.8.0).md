# V2.6 Amendment — Regulated Recurrent Initialization

**Status:** ADOPTED as a model. Adds model `0A.8.0`; it does not amend
`0A.1.0`–`0A.7.0`.

**Hypothesis result: the precommitted falsification test FAILED.** The
mechanism it predicted is confirmed and the demographic effect is large and in
the predicted direction, but three of the four precommitted absolute thresholds
were not met. See §8. Nothing was tuned after seeing those numbers, and nothing
should be until the owner has reviewed them.

`0A.8.0` is `0A.6.0` — ten inputs, eight recurrent hidden units, four outputs,
188 inherited neural parameters, solid bodies, contestable five-tick food
handling — with exactly one difference: the sigma the recurrent hidden→hidden
block is **drawn from** at founder generation.

It is deliberately a sibling of `0A.6.0`, not a successor of `0A.7.0`:
**lifetime plasticity is off**, so one variable is isolated.

## 1. The measured problem

Recurrent weights in every recurrent model so far were initialized from the
same `neural.initSigma` as the feed-forward weights.

The diagnosis is **not** generic chaos. It is a variance/fan-in mismatch with a
specific consequence chain:

1. the input→hidden block receives an external sensory vector once per tick;
   the recurrent block feeds the network's own hidden activity back into itself
   every tick, so one shared sigma makes **recurrent drive disproportionately
   large**;
2. hidden pre-activations are dominated by that drive, so hidden units sit deep
   in **tanh saturation**;
3. a saturated unit has a small tanh derivative, so **sensory conductance
   falls** — the same sensory change moves the hidden state far less;
4. the settled state generates **large state-driven output offsets**, and the
   controller **loses sensory authority** once the recurrent state settles.

Associated observations in `0A.6.0`/`0A.7.0` worlds: spinning, boundary
pushing, food-response failure, inability to sustain food handling, demographic
collapse and very few evolutionary selection events. §7 measures the chain
directly.

## 2. The change, in full

| | `0A.6.0` (and `0A.4.0`, `0A.5.0`, `0A.7.0`) | `0A.8.0` |
|---|---|---|
| input→hidden draw | `Gaussian(0, initSigma)` | `Gaussian(0, initSigma)` — unchanged |
| hidden biases draw | `Gaussian(0, initSigma)` | `Gaussian(0, initSigma)` — unchanged |
| hidden→output draw | `Gaussian(0, initSigma)` | `Gaussian(0, initSigma)` — unchanged |
| output biases draw | `Gaussian(0, initSigma)` | `Gaussian(0, initSigma)` — unchanged |
| **recurrent hidden→hidden draw** | **`Gaussian(0, initSigma)`** | **`Gaussian(0, recurrentInitSigma)`** |

with the [LOCKED] rule

```
recurrentInitSigma = initSigma / sqrt(hiddenSize)
```

At the defaults (`initSigma` 0.8, `hiddenLayerSize` 8) that is exactly
`0.8 / sqrt(8)` = `0.282842712474619`.

The value is **precommitted from the architecture**, not selected from a
sweep. `validateConfig` re-derives it and refuses any other value, so `0.1`,
`0.15` or anything else cannot be substituted after seeing a trajectory. No
seed shopping and no survival-based tuning took place.

## 3. Initialization only — what V2.6 is NOT

- **No runtime recurrent gain.** Recurrent activity is never multiplied by
  anything at evaluation time.
- **No leak, no time constant, no λ** (fixed, per-unit or evolvable). A
  follow-up experiment showed leaky/time-constant recurrence was harmful in
  this world; the hidden update stays the current Elman recurrence.
- **No LSTM, GRU, gate, cell or attention.** No structural recurrent bound.
- **No new gene.** The genome is still input→hidden (80), hidden biases (8),
  hidden→output (32), output biases (4), recurrent (64) = **188** parameters.
  `recurrentInitSigma` is model/configuration, never inherited state, and never
  appears in canonical state or in an organism record.
- **No new input, output, action, sensor or interaction.**
- **No founder screening change.** No temporal screen, no spin rejection, no
  saturation gate, no wall-avoidance or food-steering-persistence check. A
  controller that circles is still a valid founder — that may be a legitimate
  evolved strategy in another niche. V2.6 fixes the pathology at
  initialization instead of gating behaviour.
- **No ecology, handling, energy, mutation or morphology change.**

After they are drawn, the recurrent weights are **ordinary genetic
parameters**. Mutation is untouched: same enable flags, same
`neuralMutationRate` (0.05), same `neuralMutationSigma` (0.05), same bounds,
same block order, same draw schedule. **`recurrentInitSigma` is never a
mutation sigma** — the distinction is explicit in `config/types.ts`,
`genome/founder.ts` and `world/bootstrap.ts`, and pinned by test.

## 4. Draw schedule and bootstrap

`gaussian()` consumes exactly two RNG draws whatever its sigma, and the founder
viability screen evaluates every probe from a **zero hidden state**, where
recurrent weights contribute exactly nothing. Therefore, at the same seed:

- no RNG draw is added or removed;
- no draw position moves;
- founder candidates are accepted at the **same attempt indices** as `0A.6.0`;
- each founder's four historical blocks are **byte-identical** to `0A.6.0`'s;
- bootstrap positions, headings, fertility field and initial food are
  identical.

Only the recurrent block's numeric scale differs. This makes `0A.8.0` a
genuinely controlled comparison against `0A.6.0`.

**Bootstrap perturbation is unchanged**, for every block including the
recurrent one. The V2.6 brief made rescaling it conditional on that
perturbation currently using `initSigma`; inspection shows it does not and
never did — it uses the separate `neural.neuralBootstrapSigma` (0.05). The
condition therefore does not fire. Measured: at the corrected draw scale the
perturbation raises the population's recurrent standing deviation from 0.2828
to `sqrt(0.2828² + 0.05²)` = 0.2872, **+1.6%**, so bootstrap does not undo the
correction. Rescaling it would have invented a second parameter outside the
locked rule, and using `recurrentInitSigma` itself there (0.2828 ≫ 0.05) would
have inflated the recurrent scale by ~41% — undoing part of the fix.

## 6. Persistence, canonical state and the observer

`0A.8.0` **reuses snapshot format v3**. Its future-affecting state shape is
`0A.6.0`'s exactly — recurrent memory, recurrent weights, per-food `holderId`
and `handlingProgress`, and no plastic state — because an initialization rule
is not stored state. The format number describes the serialized **shape**, not
the chronological order of models:

| Format | Models |
|---|---|
| v1 | `0A.1.0`, `0A.2.0`, `0A.3.0` |
| v2 | `0A.4.0`, `0A.5.0` |
| v3 | `0A.6.0`, **`0A.8.0`** |
| v4 | `0A.7.0` |

Validation still prevents cross-model relabelling in both directions: a valid
`0A.8.0` snapshot must contain no plasticity state, a valid `0A.7.0` snapshot
still requires its v4 plastic state, and a `0A.8.0` snapshot cannot be renamed
to `0A.6.0` (its stored config carries `recurrentInitSigma`, which `0A.6.0`
must not have) or the reverse.

No new runtime field exists, so no initialization metadata enters canonical
organism state; the model/config identity already distinguishes `0A.8.0`.
Every historical canonical representation and every pinned historical
`configHash` is unchanged — `neural.recurrentInitSigma` is present **if and only
if** the model has `regulatedRecurrentInit`, exactly as `body`, `handling` and
`plasticity` are model-scoped.

Observer protocol stays **v1**. Frames carry no memory, weights, initialization
metadata, handling state or intent, and the Observatory is unchanged and
read-only.

## 7. Controller diagnostics (read-only; measured, never gated)

Four coverage seeds (5, 8, 12, 13), settled 300 ticks, averaged over all living
organisms. These are descriptive measurements from a scratch analysis script;
no production code consults them and no founder is selected by them.

| Measurement | `0A.6.0` | `0A.7.0` | `0A.8.0` |
|---|---|---|---|
| mean \|h\| (settled) | 0.791 | 0.785 | **0.650** |
| fraction of units with \|h\| > 0.95 | 0.439 | 0.438 | **0.220** |
| mean tanh derivative (1 − h²) | 0.299 | 0.309 | **0.485** |
| mean \|recurrent pre-activation\| | 1.588 | 1.544 | **0.482** |
| mean \|sensory pre-activation\| | 0.877 | 0.864 | 0.889 |
| recurrent / sensory drive ratio | 2.64 | 2.39 | **0.75** |
| turn swing (food hard-left → hard-right) at settled memory | 0.328 | 0.315 | **0.668** |
| same swing at zero memory | 0.601 | 0.583 | 0.635 |
| **sensory authority** (settled ÷ zero) | 0.545 | 0.541 | **1.052** |
| mean \|turn\| (spinning proxy) | 0.622 | 0.619 | **0.337** |
| wall-near fraction (< 20 units) | 0.310 | 0.290 | 0.340 |
| food-in-range with eat not requested | 0.020 | 0.030 | 0.000 |

The proposed causal chain is confirmed end to end: recurrent drive falls ~3.3×,
saturation roughly halves, the tanh derivative rises ~1.6×, the settled
controller retains ~100% of its zero-memory sensory responsiveness instead of
~54%, and persistent turning drops ~46%. Sensory pre-activation magnitude is
unchanged, as it must be.

This is mechanism evidence. It is not evidence of intelligence.

## 8. Precommitted population evaluation — **FAILED**

The seed sets, tick counts and thresholds below were fixed and written to
`results/v2.6/PRECOMMITMENT.md` **before any of these runs**.

The prior read-only recurrence diagnostic's 17 seeds are not reproducible from
this repository (no analysis note or script records them), and the Phase 0B
pilot/validation seed sets are reserved (AGENTS.md §4, §7). The precommitted
substitute is the first N of the natural counting order — seeds **1–17** at
5,000 ticks and seeds **1–7** at 12,000 ticks — the same convention V2.2 and
V2.4 used when they needed coverage seeds. No seed was chosen, swapped or
dropped after a result was seen.
