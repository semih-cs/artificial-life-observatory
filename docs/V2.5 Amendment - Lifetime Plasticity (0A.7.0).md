# V2.5 Amendment — Lifetime Plasticity

**Status:** ADOPTED. Adds model `0A.7.0`; it does not amend `0A.1.0`–`0A.6.0`.

`0A.7.0` is the `0A.6.0` world—ten inputs, eight recurrent hidden units,
four outputs, 188 inherited neural parameters, solid bodies and contestable
five-tick food handling—plus deterministic lifetime adaptation of the final
action readout.

> Genome = inherited controller baseline. Plastic state = learned lifetime
> adaptation.

The genome remains immutable throughout life. Learned state is runtime
phenotype state, starts at zero for founders and newborns, consumes no RNG,
and is never inherited or mutated. This is not Lamarckian inheritance.

## 1. Model and controller

| Model | Controller | Plasticity | Snapshot |
|---|---|---|---|
| `0A.1.0`–`0A.3.0` | historical feed-forward | none | v1 |
| `0A.4.0`–`0A.5.0` | 10 → 8 recurrent → 4 | none | v2 |
| `0A.6.0` | same recurrent controller + food handling | none | v3 |
| `0A.7.0` | same recurrent controller + food handling | final readout only | v4 |

The genetic topology and parameter order remain unchanged. There are still
188 inherited parameters and the same outputs: forward, turn, eat and
reproduce. No input, neuron, recurrent unit, output or action was added.

Only these effective parameters can change during life:

- 32 hidden→output connections (`8 × 4`);
- 4 output biases.

Each has one runtime offset, for exactly 36 offsets. Input→hidden weights,
hidden biases and all 64 recurrent weights remain the immutable genetic
values. Effective readout parameters are `geneticBase + runtimeOffset` and
are kept inside the existing `neuralParamBounds`; the stored offset is the
bounded effective value minus the genetic base.

## 2. Eligibility and learning rule

Each plastic parameter has one runtime eligibility trace, for exactly 36
traces. With the raw outputs that produced the current action:

```
centeredForward   = 2 × rawForward - 1
centeredTurn      = rawTurn
centeredEat       = 2 × rawEat - 1
centeredReproduce = 2 × rawReproduce - 1

E_weight[h,o] = 0.90 × oldE_weight[h,o]
                + hiddenActivation[h] × centeredOutput[o]
E_bias[o]     = 0.90 × oldE_bias[o] + centeredOutput[o]
```

The actual recurrent hidden activation that generated the action is used;
thresholded action booleans are not. Eligibility advances once on every acting
tick even when reinforcement is zero.

After movement and food credit are resolved:

```
metabolicOutcome = actualFoodEnergyCredited - actualMovementEnergySpent
reinforcement    = clamp(metabolicOutcome / energyCapacity, -1, +1)
offset           = offset + 0.01 × reinforcement × eligibility
```

The learning rate is exactly `0.01`; eligibility decay is exactly `0.90`.
Learning is deterministic and RNG-free: no backpropagation, optimizer, replay,
world gradient, neural target or stochastic policy exists.

Only energy actually credited after the existing energy cap is positive.
Movement uses the existing actual resolved movement cost. Basal metabolism,
age, reproduction cost, mutation, survival, offspring, proximity, seeing food,
acquisition, holding, handling progress and collision are excluded. In
particular, reproduction cost does not teach the lifetime controller not to
reproduce.

The five-tick food delay has no special reward. Only completed feeding credits
energy; surviving eligibility traces provide temporal credit to earlier neural
activity.

## 3. Tick timing and memory

Sense → Decide → Resolve is preserved:

1. sense the authoritative pre-decision state;
2. evaluate the recurrent controller with the current offsets;
3. select the action, buffer the next hidden state and advance eligibility;
4. resolve movement/body contact and charge the existing movement cost;
5. resolve contestable handling and credit completed food at the cap;
6. compute metabolic reinforcement and update offsets;
7. continue through reproduction, death, births, regeneration and tick advance.

The current action is never recomputed. Learning affects future decisions
only. Recurrent `hiddenState` remains fast neural memory advanced once per
acting tick. Offsets and eligibility are separate slow learned state. Learning
does not reset memory or change recurrent weights.

## 4. Founders, mutation and inheritance

Founder genomes use exactly the `0A.6.0` genetic draw schedule. Founder
screening evaluates the baseline recurrent controller from zero memory and
zero offsets; it does not run a learning episode or require learned behavior.

Genetic mutation rates, sigmas, ordering and RNG draws are unchanged. A child
inherits and mutates the 188-parameter genetic genome normally. Its recurrent
memory, 36 offsets and 36 traces all begin at exact zero, regardless of its
parent's experience. Plastic state is neither mutated nor an RNG consumer.

## 5. Canonical state and persistence

Plastic state changes future decisions, so `0A.7.0` canonical organism records
include recurrent memory, all four plastic arrays, and the existing genetic
genome. Existing per-food handling state remains canonical. Two worlds that
differ only in learned state hash differently.

Snapshot format v4 stores all of this state. Validation requires exact array
dimensions, finite values and bounded effective parameters, refuses missing state, forbids plastic fields on
historical models, and rejects cross-model/format relabelling. Nothing is
migrated and no learned state is invented for an old snapshot. Exact
continuous-versus-resumed learning trajectories are live regressions.

## 6. Observer boundary

Observer protocol remains v1. Frames expose no hidden state, learned offsets,
eligibility, reinforcement, reward, neural input, weight or intent. The
Observatory remains read-only and unchanged.

## 7. Canonical regression and descriptive observation

On the canonical linux-arm64 environment (official Node 22.23.2 image), seed
20260910 has checkpoints `3430a275c26406f2` (tick 500),
`9cf7240aa1ca863e` (tick 1,000), and `cfeb892aecfbaf91` (tick 2,000), then
becomes extinct at tick 2,444 with zero births. Its 10,000-tick golden hash is
`04d0b7c5917ca0c0`. This is a trajectory fingerprint, not evidence of improved
behavior.

A descriptive seed-8 comparison over 6,000 ticks found: `0A.6.0` population
46, 118 births, 6,649 acquisitions and 675 completions; `0A.7.0` population
47, 103 births, 5,043 acquisitions and 557 completions. Neither was extinct.
Living `0A.7.0` organisms had mean absolute offset 0.02257 and maximum 0.23663.
Release counts combine voluntary releases, dislodgements and death releases
because the persisted state transition does not label their cause. This one
coverage trajectory supports no causal or intelligence claim and was not used
to tune the fixed learning values.

## 8. Explicitly not added

Backpropagation, BPTT, gradient descent, Adam/SGD, Q-learning, DQN, PPO,
episodes, replay, targets, external reward, hand-written action rewards,
wall-avoidance/eating/chase/flee/food-preservation strategies, attack,
predation, damage, signalling, communication, new sensors/actions/neurons,
plastic input or recurrent weights, evolved learning rates, learned-state
inheritance, ecology/mutation/food/collision tuning, observer changes,
plasticity UI, ML libraries, workers, GPU code or unrelated refactors.
